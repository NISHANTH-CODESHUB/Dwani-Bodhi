# Decisions log

| Date | Decision | Why |
|---|---|---|
| 2026-10-17 | Reading scored by ECCL (closed-set CTC lattice), not open ASR or an LLM | Child ASR is unreliable; the closed set types errors by construction; zero token cost |
| 2026-10-17 | CTC maths in NumPy, acoustic model behind a protocol | Scoring is testable without torch; model and scoring scale on different workers |
| 2026-10-17 | Dialect variants enter the lattice *before* error mutations | Otherwise a visual-error candidate (ब↔व) with identical text shadows the tolerated variant |
| 2026-10-17 | Bugs expressed in a small `ProcedureSpec` grammar | One executor for the library and for Claude's hypotheses; no execution of generated code |
| 2026-10-17 | Item generator keeps bug predictions that look like slips | A dropped carry always looks like a tens-digit slip; filtering it removed the most common bug |
| 2026-10-17 | Misconception prior Beta(1,2); confirm at mean ≥ 0.6 and ≥ 2 reproductions | An exact reproduction is strong evidence; Beta(1,4) needed about 5 reproductions |
| 2026-10-17 | Prerequisite propagation only on success | Failure on an advanced skill is weak evidence about prerequisites (fixes v1 error T5) |
| 2026-10-17 | TaRL ladders instead of clustering | Teachers already understand TaRL levels; clusters aren't interpretable |
| 2026-10-17 | DB-backed job queue (SKIP LOCKED) instead of Redis/Celery | One fewer service; scales per queue; enough for district scale |
| 2026-10-17 | PWA (React/TS) instead of Flutter | URL-demoable, no Android toolchain, offline via service worker; Capacitor wrap later |
| 2026-10-17 | LLM offline fallbacks everywhere | The product must work without a key, over budget, or during an outage |
| 2026-10-17 | Slate transcription prompt is expectation-constrained | Known operands reduce ambiguity; the model reports what is written, not what is correct |
| 2026-10-17 | Default acoustic model = EkStep Vakyansh Hindi wav2vec2 (MIT) | Smoke test found `ai4bharat/indicwav2vec-hindi` is gated on Hugging Face; Vakyansh is open, covers all 53 pack characters, RTF 0.066 on CPU |
| 2026-10-17 | CTC blank detected empirically at model load | Smoke test found the fairseq-converted model's real blank is `<s>` (id 0), not the configured `<pad>` (id 1) |
| 2026-10-17 | ECCL includes a "nothing said" null hypothesis | Smoke test found silence was scored CORRECT: with no evidence, the mistake prior handed the win to the target |
| 2026-10-17 | UI v2: teacher app shell with bottom tabs, dashboard, plain-language skill bands; kiosk "world" with star-trail journey | Teachers need numbers at a glance, not decimals; children need play and effort rewards (never right/wrong signals) |
| 2026-10-17 | Multiple-choice taps never propagate to prerequisite skills | A lucky 1-in-4 comprehension guess must not raise decoding skills |
| 2026-10-17 | Kiosk skips comprehension questions after a silent passage | Nothing was read, so there is nothing to comprehend; the question is pure guessing |
| 2026-10-17 | Recorded-clip manifest instead of probing each audio file | One request instead of many on 2G; a missing file now returns 404 instead of the app shell |
| 2026-10-18 | UI v3: navy sidebar (≥1024 px) / drawer + 5-tab bar (phones), royal-blue primary, SVG icons instead of emoji, one shell for every screen | Professional, consistent look on phones, tablets and CRCC laptops; emoji render differently across Android versions; every screen reachable in ≤2 taps |
| 2026-10-18 | Level-distribution bars use a single-hue sequential ramp with 2 px gaps and an always-visible legend | Levels are ordinal; multi-hue (red→green) implied good/bad judgements about children and failed colour-blind separation |
| 2026-10-18 | Kiosk styles split into kiosk.css, untouched by the teacher redesign | The child experience is deliberately playful and was already validated with the target age group |
| 2026-10-18 | Vite dev/preview proxy `/v1` and `/health` to :8000 | README promised it but vite.config had no proxy, so `npm run dev` login returned 404 |
| 2026-10-23 | Misconceptions confirm only on ≥2 *verified* reproductions (designed-probe ECCL hit, symbolic slate reproduction, or teacher confirmation); tap distractors and un-probed errors are weak evidence | Two lucky-guess taps were enough to "confirm" a misconception — a direct violation of the no-unverified-claims rule |
| 2026-10-23 | Classroom endpoints are teacher/global-admin only; CRCC uses `/v1/crcc/*` | CRCC could read child rows and even change a child's consent via the shared classroom check |
| 2026-10-23 | Confirm accepts only `unsure` responses (409 otherwise) and validates the rule | Re-confirming added the same evidence again; the incremental learner model cannot subtract the old verdict |
| 2026-10-23 | Full classroom slate photos deleted right after cropping; crops expire after `SLATE_CROP_RETENTION_DAYS` (30) | Photos may contain faces and had no retention at all |
| 2026-10-23 | Erasure also removes slate crops (found via the child's slate responses), sessions, child-scoped jobs and the cost-log reference | Crops and session rows survived `DELETE /children/{id}` |
| 2026-10-23 | Every CRCC level cell must itself hold ≥ k children; recheck counts suppressed too; UI notes when cells are hidden | The `n ≥ 4k` exemption published 1-child cells |
| 2026-10-23 | Action Cards split confusion counts into confirmed vs suspected; template and Claude must hedge suspected ones; validator rejects un-hedged text; one retry before the template | Cards stated suspected confusions as fact |
| 2026-10-23 | Any Claude failure (schema validation, truncation, auth, missing key) → logged `LLMUnavailable` → template/teacher queue | Validation errors escaped as 500s and were never logged |
| 2026-10-23 | 5 wrong PINs per phone → 15-minute lockout (per-process) | A 4-digit PIN was brute-forceable; Redis needed only if the API is scaled out |
| 2026-10-23 | Review queue ranked server-side (verifies a suspected confusion > unread slate > expiring audio; unverifiable items last) and shown in batches of 5 with a stopping point and a skip | 40 undifferentiated items vs a 0–3 min/week teacher budget; teachers should never be pushed to guess |
| 2026-10-23 | Approved discovered bugs load into the live library at API/worker start and on approval; discovery runs weekly | Approval previously changed nothing |
| 2026-10-23 | Dev SQLite `create_all` also adds new nullable/defaulted columns | Existing dev databases broke after schema changes; production still uses Alembic |
| 2026-10-23 | PIN policy: 6–12 digits; rejects ≤2 distinct digits, sequences, common PINs and phone-derived PINs; same rules mirrored in the PWA | A 4-digit PIN is 10,000 guesses, and the published demo PIN was `1234` |
| 2026-10-23 | A weak PIN at login yields a 15-minute token scoped to `POST /v1/auth/pin` only | Legacy accounts upgrade themselves; the server enforces it, not just the UI |
| 2026-10-23 | PIN change sets `credentials_changed_at`; tokens issued before it (precise `ts` claim) are rejected | 30-day tokens were otherwise irrevocable; a lost phone could keep access |
| 2026-10-23 | Demo accounts get random phones and PINs per database, printed once and saved to git-ignored `data/demo-credentials.txt`; no credentials in docs | Credentials should never be published; the seeder issues its own token instead of logging in |
| 2026-10-23 | Admin-created users and `cli create-admin` get a generated PIN when none is given, returned once | The safest PIN is one nobody chose |
| 2026-10-24 | Dev/demo no-login mode: `AUTH_DISABLED=1` enables `POST /v1/auth/open {role}` (first active user of that role); web `VITE_NO_LOGIN=1` shows one-tap role buttons. Startup refuses it in prod | Login was removed temporarily for demos; keeping the token flow means every endpoint and role check is unchanged |
