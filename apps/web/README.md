# ध्वनि-बोधि — teacher/kiosk PWA (`apps/web`)

Offline-first Progressive Web App for one low-end Android phone (2 GB RAM, Chrome) owned by the teacher.
Vite + React 18 + TypeScript, react-router, Dexie (IndexedDB), vite-plugin-pwa (Workbox). No UI library.

## Run

```bash
cd apps/web
npm install
npm run dev            # http://localhost:5173  (API: same origin unless VITE_API_BASE is set)
npm test               # Vitest unit tests
npm run build          # type-check (tsc) + production build into dist/ (with service worker)
npm run build:demo     # same, with VITE_DEMO=1 (see below)
npm run preview        # serve dist/ locally
```

Against a local API (`services/api`, default port 8000):

```bash
VITE_API_BASE=http://localhost:8000 npm run dev
```

The API allows CORS `*` by default. In production, serve `dist/` from the same origin as the API
(e.g. Caddy: `/v1/*` → FastAPI, everything else → `dist/`), so `VITE_API_BASE` can stay empty.
The service worker needs HTTPS (or `localhost`).

### Environment

| Variable | Meaning |
|---|---|
| `VITE_API_BASE` | API origin, e.g. `https://api.example.in`. Default: same origin. |
| `VITE_DEMO=1` | Demo build: voice items show a text box ("बच्चे ने क्या बोला?"); the typed text is sent as `payload.simulated_utterance` for the backend's simulated scorer. No microphone needed. Never use in the field. |

### Cheenu's recorded prompts

Put MP3 files in `public/audio/hi/<key>.mp3`. Keys are the prompt keys from `content/packs/hi-IN/prompts.yaml`
(`welcome`, `akshara`, `word`, `nonword`, `passage`, `repeat`, `question`, `try_again_louder`, `next`, `bye`)
or an item id (e.g. `hi.rep.van.mp3` for a listen-and-repeat word, `m.tap.47.mp3` for a tap prompt,
`hi.p.b1.a.q1.mp3` for a passage question). They are precached by the service worker. Missing clips fall back to
the phone's Hindi TTS (`speechSynthesis`, `hi-IN`).

Icons are generated by `node scripts/gen-icons.mjs` (no image dependencies).

## How it works

* **Privacy.** Child names are typed by the teacher and stored only in IndexedDB. The roster is pushed as
  `{id, grade, aruco_slot, gender, consent_status}` (`toChildOut`, unit-tested to contain no name). Server text with
  `{{child}}` is filled in on the phone. Uploaded audio/photos are deleted from the phone once the server has them.
  Assessment is blocked unless consent = `granted`.
* **Offline kiosk.** The plan for each child (from `/today` or `/children/{id}/plan`) and the content pack
  (`/bootstrap`, re-downloaded when `content_version` changes) are cached. Each response and its audio blob is written
  to IndexedDB immediately. Within-session rule: if the first N (`discontinue_after_silent_aksharas`) akshara items
  get no speech, the runner skips to the blocks in `on_discontinue` (default control, numeracy, closing).
* **Recording.** One mic stream per session, `audio/webm;codecs=opus` preferred (falls back to ogg/mp4/aac), 16 kHz mono
  constraints, 24 kbps. VAD on 50 ms RMS frames: stop on `silence_timeout_s` with no speech, on end-of-utterance
  silence after speech (1.2 s; 3 s for passages; never more than `silence_timeout_s`), or at
  `max_item_seconds[type]`. Too little speech → "थोड़ा ज़ोर से बोलो" once, then re-record.
* **Sync.** Triggers: `online` event, every 2 min while open (if queued work or stale), app becoming visible, end of a
  kiosk session, the "अभी सिंक करें" button. Order: roster → sessions/photos in ≤ 5 MB, ≤ 25-object multipart batches
  → refresh bootstrap/today/roster/unsure count/card. Exponential backoff with jitter (15 s … 30 min). A permanent
  4xx on a batch is retried object-by-object so one bad object is isolated and marked rejected.

## Tests

`npm test` runs Vitest on the pure modules:

* `src/lib/audio.test.ts` — VAD stop rules, onset debounce, noisy-room adaptation, immediate speech, quiet detection
* `src/lib/sync-core.test.ts` — batching under the byte cap, manifest + file parts, accepted/duplicate/rejected mapping, backoff, no names in roster payload
* `src/kiosk/runner.test.ts` — step expansion (passage questions), discontinue rule incl. custom N/blocks, skips
* `src/lib/image.test.ts` — downscale sizing and quality/shrink math
